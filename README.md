# 🐍 Cyber Snake

**Cyber Snake** is a high-octane, neon-infused reimagining of the classic snake game, built with Vanilla JavaScript and HTML5 Canvas.

## 🕹️ A Tribute to the Golden Era
Remember the days of tiny monochrome screens and the simple joy of chasing pixels? This project was born from a deep **nostalgia for the arcade classics** of the 80s and 90s. 

My goal was to capture that "one more try" addiction and blend it with a modern **Cyberpunk aesthetic**. It’s a bridge between the childhood memories we cherish and the modern web technologies I love to build with.

## 🚀 Key Features
* **Dynamic Difficulty:** The grid accelerates as you collect data (food), testing your reflexes.
* **Gold Rewards:** Rare golden nodes provide massive score boosts but increase speed significantly.
* **Persistence:** High scores are saved locally using `localStorage`.
* **Cyber-Aesthetic:** Smooth gradients, neon glows, and a responsive UI.

## 🛠️ Built With
* **HTML5 Canvas** for high-performance rendering.
* **Vanilla JavaScript** (No heavy libraries, pure logic).
* **Modern CSS3** for the retro-futuristic atmosphere.
